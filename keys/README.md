# SSH-ключі

Кожен `*.pub` у цій папці потрапляє в образ і дає вхід у **всі три** контейнери під користувачем `deploy`.
Сюди кладуться тільки **публічні** ключі. Приватні не комітити ніколи.

- `<нік>.pub` — ключі людей, які адмініструють контейнери (наприклад `catdlia.pub`, `maksym.pub`).
- `github-actions.pub` — ключ, яким заходить CI/CD. Його приватна половина лежить у секретах організації на GitHub (`DEPLOY_SSH_KEY`).

Згенерувати ключ для CI:

```bash
ssh-keygen -t ed25519 -N "" -C github-actions@iasa -f github-actions
# github-actions.pub -> сюди, вміст github-actions -> секрет DEPLOY_SSH_KEY, сам файл видалити
```

Після зміни ключів образ треба перезібрати: `docker compose up -d --build`.
Дані в томах при цьому не втрачаються.
